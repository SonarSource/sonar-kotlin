Why is this an issue?

Duplicated string literals make the process of refactoring complex and error-prone, as any change would need to be propagated on all occurrences.

Exceptions

To reduce noise, the rule ignores:

  • String literals of five characters or fewer
  • String literals containing only letters, digits, or _
  • String literals in annotations
  • Interpolated strings
  • String literals passed to Kotlin’s TODO function
  • Adjacent literal fragments in string concatenations
  • String literals in test files
  • String literals inside functions directly annotated with a Compose @Preview annotation (Jetpack Compose’s androidx.compose.ui.tooling.preview.Preview or Compose Multiplatform’s org.jetbrains.compose.ui.tooling.preview.Preview). This includes default arguments and local declarations. Helpers declared outside the function remain in scope

Repeated literals in these contexts do not raise an issue on their own and are not counted towards the threshold:

  • Calls to recognized logging APIs: Android Log, Java Util Logging, Kermit, Kotlin Logging, Ktor Client Logging, Log4j 2, Napier, SLF4J, and Timber
  • Arguments of exception constructors directly used in throw expressions
  • Calls to Kotlin’s error, require, and check functions

If the same literal is duplicated enough times elsewhere, these occurrences are also reported as secondary locations.

How to fix it

Use constants to replace the duplicated string literals. Constants can be referenced from many places, but only need to be updated in a single place.

Code examples

Noncompliant code example

With the default threshold of 3:

import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.ui.tooling.preview.Preview

class A {
    fun run() {
        prepare("string literal")    // Noncompliant - "string literal" is duplicated 3 times
        execute("string literal")
        release("string literal")
    }

    fun method() {
        println("'")                 // Compliant - literals of five characters or fewer are excluded
        println("'")
        println("'")
    }
}

@Preview
@Composable
fun preview() {
    Text("preview placeholder")  // Compliant - literals inside directly annotated Compose previews are excluded
    Text("preview placeholder")
    Text("preview placeholder")
}

Compliant solution

import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.ui.tooling.preview.Preview

class A {
    companion object {
        const val CONSTANT = "string literal"
    }

    fun run() {
        prepare(CONSTANT)    // Compliant
        execute(CONSTANT)
        release(CONSTANT)
    }

    fun method() {
        println("'")                 // Compliant - literals of five characters or fewer are excluded
        println("'")
        println("'")
    }
}

@Preview
@Composable
fun preview() {
    Text("preview placeholder")  // Compliant - literals inside directly annotated Compose previews are excluded
    Text("preview placeholder")
    Text("preview placeholder")
}
